Devido ao grande tamanho do arquivo, o dataset [Microdados do ENEM](https://www.gov.br/inep/pt-br/acesso-a-informacao/dados-abertos/microdados/enem) encontra-se armazenado fora deste repositório, podendo ser acessado [aqui](https://drive.google.com/file/d/1g3pwpE1oSFu7NqejAmkkbTOwCMW4So5O/view?usp=sharing) via Google Drive.

Ele é utilizado nas análise dos seguintes módulos:
- Linguagem R com Foco em Análise de Dados
- Linguagem Python com Foco em Análise de Dados
- Estatística – Análise Descritiva, Probabilidade e Inferência com R
- Estatística – Análise Descritiva, Probabilidade e Inferência com Python

Está disponível também um dicionário de dados sobre o mesmo dataset, acessível [aqui](https://docs.google.com/spreadsheets/d/1mZJJjY5nfiVPciMZttMW1ZRlPpM2qepB/edit?usp=sharing&ouid=108816664630616598989&rtpof=true&sd=true).
