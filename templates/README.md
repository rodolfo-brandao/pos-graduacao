# Templates

Neste diretório deixo salvo o template oficial da [Sociedade Brasileira de Computação (SBC)](https://www.sbc.org.br/), do qual servirá como apoio para o desenvolvimento do artigo científico do TCC da pós-graduação.

O mesmo pode ser acessado [aqui](https://www.sbc.org.br/documentosinstitucionais/#publicacoes) e baixado navegando sobre o menu: _Templates para Artigos e Capítulos de Livros_ > _Modelos para Publicação de Artigos_
